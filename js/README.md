## Project Description

This project is a simple JavaScript console program for managing an Ikimina savings group. It uses JavaScript fundamentals learned during Week 05, including variables, strings, numbers, conditions, loops, and functions.

## Project Objectives

- Format member names and phone numbers.
- Calculate yearly savings and interest.
- Calculate each member's total contributions.
- Determine members' savings statuses.
- Display savings levels and star bars.
- Calculate the group total and identify the top saver.
- Estimate the number of weeks needed to reach the savings goal.
- Use reusable functions to organize the program and test results.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Open the browser Developer Tools by pressing `F12`.
5. Select the Console tab to view the program output and test results.
